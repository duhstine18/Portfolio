# Glassmorphism Student Portfolio

A responsive, single-page portfolio made using plain HTML, CSS, and JavaScript. No install or build step is required.

## Personalize before submitting
1. Open `index.html`. Replace `YOUR NAME HERE`, `[Your Name]`, the introduction, and the About text with your real details.
2. Edit the Skills section to reflect abilities you genuinely have.
3. Replace both example projects with *your actual projects*. Update the description, contribution, and tags. Replace the illustrated placeholder previews with screenshots (you may add an `images/` folder), and add links only when they are real and working.
4. Change `your.email@example.com` in both the `mailto:` link and the visible text.
5. Update the page `<title>` and meta description.
6. Test the navigation, mobile menu, and email link on desktop and mobile.

## Preview
Open `index.html` in your browser or use VS Code with Live Preview.

## Publish with GitHub Pages
1. Create a *public* GitHub repository named `portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and any asset folders **to the repository root**.
3. Go to Settings > Pages > Build and deployment > Deploy from a branch.
4. Choose `main` and `/(root)`, then Save.
5. After publication, test your public URL (`https://YOUR-USERNAME.github.io/portfolio/`) on a phone and in an incognito window.

## Assignment notes
- This is a starter template. The screenshots and sample projects are **not** presented as real completed work.
- The email button uses `mailto:` and opens a visitor's email app; it does not submit a contact form.
